title: Currencies
description: Track subscriptions in any currency.

Not everything you pay for is billed in the same currency. Obol lets each subscription carry its own, so the amounts you enter always match what you're actually charged.

## Choosing a currency

When you add a subscription, pick its **Currency** right next to the **Cost**. Enter the cost in that currency - Obol handles the formatting (decimal places, symbol) to match.

## When the currency locks

You can freely change a subscription's currency **until its first payment is recorded**. After that, the currency is locked and the picker is disabled.

This is deliberate: once you have payment history in a given currency, switching would make those past amounts ambiguous. If you genuinely need to change it, you'd start from a subscription with no payments recorded.

## Totals across currencies

The dashboard totals and the [Reports](/obol-user/reports/) add up across every subscription, so Obol converts each one into a single display currency to produce a combined figure. Because exchange rates move, a converted total is shown as approximate.
