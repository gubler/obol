# Reference

Durable project context that isn't the code itself.

- `adr/` - Architecture Decision Records: numbered, append-only notes on
  significant choices and *why* they were made (Michael Nygard format). Start at
  `0000-record-architecture-decisions.md`.
- `out-of-scope/` - decisions to *not* do something, so they don't get
  re-litigated. Create it when you have the first one.

Issues and PRDs live in the tracker, not here.
