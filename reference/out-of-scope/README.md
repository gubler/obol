# Out of scope

Things deliberately not being built. Recording them here keeps them from being
re-proposed and re-litigated. Drawn from the product roadmap and CRUD specs that were
migrated out of the retired `.agent-os` scaffold.

## Not building

- **Multi-user / household sharing** - Obol is single-tenant (see ADR-0004). No accounts,
  no per-user data, no sharing a dataset between people.
- **Teams / businesses** - no organization or company-account model.
- **Public API** - no REST/GraphQL surface for external consumers.
- **Real-time bank / payment-provider integration** - payments are entered manually or
  generated by the scheduler, never pulled from a bank feed.
- **Multi-currency** - costs are tracked in a single currency.
- **PWA / mobile-first / native app** - web UI is the only target.
- **Nested or hierarchical categories** - categories are a flat list.
- **Bulk category operations** - no bulk edit/delete of categories.
- **Category icons or colors** - categories carry a name only. (Note: this is distinct
  from #52, an application icon/favicon for Obol itself, which is in scope.)

## If one of these comes back

Reopen the decision explicitly (an ADR superseding the relevant point), rather than
quietly adding the feature. Several of these are load-bearing simplifications - e.g.
dropping single-tenancy pulls in an entire auth stack.
